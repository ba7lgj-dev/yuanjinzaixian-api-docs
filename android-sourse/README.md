# 远近电量 Android

通过远近在线外电电压估算 60V 铅酸电池 SOC，并提供 4x1 桌面小组件、满/空标定、历史行程、载人标注和本地续航模型。

## 构建

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```

Debug APK：

`app/build/outputs/apk/debug/app-debug.apk`

可直接安装的 1.1 构建：`dist/远近电量-1.1-debug.apk`

## 当前能力

- 账号登录，密码和 `sid` 使用 Android Keystore 加密保存。
- 后台 WorkManager 未稳定时每 15 分钟读取一次，稳定后切换为每 60 分钟普通读取；App 打开时不自动采样。
- 小组件显示当前电压即时 SOC；静置 15 分钟后提供灰色临时估算，静止满 30 分钟且最近两个通讯样本差不超过 0.05V 时建立可信稳定值，150 分钟后为高置信度。
- 只使用 `external_voltage` 作为电池 SOC 依据；`power` 是定位器电量，`acc_state`/`acc_power` 不参与车辆判断。
- `last_com_time` 是电压唯一主时间；只有通讯时间推进时才记录新电压，`last_pos.time` 仅用于地址和诊断。
- 稳定电压使用 60V 铅酸 OCV 曲线；默认静置满电 65.5V、实际空电 55.0V。
- 4x1 小组件：AIMA 图标 + 昵称 + 加粗自绘电量条，带 E/F 端点、20% 刻度线和悬浮三角指针；右侧不稳定时显示百分比，稳定后显示预计续航。三角绿色表示稳定，灰色表示临时/反弹/未知/过期。
- 小组件严格限制为 4 横向 × 1 纵向（`minHeight=40dp`），不显示地址；点击小组件只普通读取 `device/GetDetail` 和地址，不下发立即定位，不打开 App。
- App 在电压不稳定时显示“最近静止起点到现在”的电压折线。
- 疑似充电/反弹通知带“充过电 / 没充电 / 不确定”按钮。
- 设置页可保存车辆昵称；默认回退到平台备注、车牌号或“我的车”。
- 满电标定进入待定状态，稳定后写入 100%，24 小时未稳定自动失效；空电标记立即写入 0%，不再预留 20% 续航。
- App 首页已简化：显示 AIMA 图标、昵称、定时地址、电量条、百分比/续航；不可信时显示小型电压折线；返回在子页回上一层，主界面双击返回退出。

## V2：历史行程与实时剩余距离

- 只读导入平台历史：`QueryTrackDate`、`QueryLocation`、`PPoint`、`PDistance`；首次回填最近两年，之后每天增量同步最近两天。
- 从久静置停留建立训练锚点，自动拼出“静置 A → 多个骑行区间与暂停点 → 静置 B”的周期。
- 历史页按天展示：最近 7 天可点击进入行程详情标注人数；暂停边界由平台自动生成且只读；更早记录按月份折叠只读。
- 首页和小组件以“剩余公里”为主数字：锚点预测距离减去锚点以来的实际行驶距离；无有效锚点时回退到百分比。
- 载人数量 1–2 人（含骑行者，每人约 70kg），可在首页快捷切换，设置页保存默认值。
- 少于 5 个合格周期使用物理基准；5–9 个使用人数/SOC 区间中位数；10–29 个使用带正则回归；30 个以上使用分 SOC 区间回归，并纳入海拔、速度、加速度和动能回收代理特征。
- 模型只在本机训练；支持回滚上一版和恢复物理基准。
- 仍然不主动定位、不追踪，实时电压只认 `last_com_time`，定位器电量与 ACC 不参与计算。

详细算法、数据边界与验收规则见 [docs/plans/battery-trip-learning-v2.md](docs/plans/battery-trip-learning-v2.md)。

## 1.1：导航与操作规范

- 底部三栏：首页、历史、设置；行程详情和诊断作为二级页，使用标准返回栈。
- 所有操作使用“标题 + 一行作用说明”；危险操作（重置标定、恢复物理基准、退出登录）需要二次确认。
- 设置页按账号与车辆、电量标定、载人设置、历史与模型、应用与后台、支持与诊断、账号操作分组。
- 数据库升级到 v8：旧 3–4 人标注压缩为 2 人，停用旧模型并在下次启动按新人数规则重训；轨迹、电压历史和标定保留。
- 页面图、返回规则与迁移 SQL 见 [docs/plans/ui-navigation-v2.md](docs/plans/ui-navigation-v2.md)。
