API接口目前分为以下11个模块：
账户(user)：账号登录，获取等相关操作
设备(device)：设备的导入，添加，删除，转移，修改等批量或者单操作
车组(family)：根据组织获取相关信息的操作
告警模块(alarm) ：获取告警等相关操作
sim卡(sim)：sim卡的信息获取，充值，远程开关机等相关操作
定时开关机(timerswitch)：定时开关机功能的相关操作
轨迹(location)：获取历史轨迹，实时追踪，获取轨迹统计相关操作
模式(loc)：设置获取设备的模式等相关操作
围栏(fence)：设备的围栏相关操作
统计(summary)：一些混合的统计相关

关于接口：
目前整个系统的接口url都是相同的，通过post参数中module字段来确认模块名,func参数确认接口名，params参数就是相应的json参数，也将返回json格式的数据。
枚举值采用的是字符串模式，请根据文档自行选择。
每个说明文档中示例部分的参数，是系统自动随机生成的，没有意义，示例部分只是给用户提供数据以及格式的参考。


关于参数:
目前整个系统识别设备号采用的是simei，也就是系统对设备表示的唯一id，是一串加密的字符串，通过组织拉取等方式获取到simei之后，就可以对这个simei进行相关操作
同样的sfamily为组织id，sgid为分组的id，围栏id等都是一串加密的字符串。对于系统来说imei号仅给前端展示作用。或者如果看到simei是字符串，多半是设备id，而不是imei号，如果是整形，那么就是imei号。比较特殊的是device模块下的Load接口，由于需要兼容php中文件格式的导入，所以这里的imei号是字符串格式的，但是需要传入的是imei号，而不是设备id。

关于sid：
sid是整个系统的登录凭证，通过user模块下的Login接口获取到本次登录的sid，那么以后的接口都需要通过url的Get的参数将sid传入到系统中作为本次登录的凭证。
凭证如果长时间没有使用（没有调用任何接口）。那么将在2天内过期，过期之后，再次使用，任何接口都会返回错误码268697631，提示登录态已过期，请重新登录。
并且对sid的个数也做了相应的限制，针对同一个账号，同时只允许100个有效的sid，如果sid使用超过限制，会提示268697629，提示操作频率过快,请稍后再试。
如果因为这个原因报错，请先调用user模块下的LoginOut退出部分的sid。或者等2天之后再操作，sid的有效期超期之后，自动无效。


关于限频限速：
系统针对单个模块的单个接口做了相关的限频限速，目前是100ms限制调用一次。1分钟内可以请求500次的调用。请注意频次，如果超过了限制，将返回268697629，提示操作频率过快,请稍后再试。
前端可以通过适当的usleep等相关操作控制频次。


关于列表：
目前整个系统拉取列表的操作，采取的是瀑布流模式的翻页，也就是需要拉取第二页的时候，需要返回第一页最后一条数据相关参数给服务器，
第一页的时候，最后一条的相关参数可以不填。如果接口在返回值中有明确返回最后一条信息，那么就应该下一页获取的时候，以服务器返回的信息为准，请不要自己计算上一页返回的数据，比如模块device下接口GetLog,有明确返回last_time，last_imei，那么下一页请求接口GetLog的时候，传入参数last_time，last_imei就应该以这个为准。
如果接口没有明显返回上一页的最后一条数据，则前端根据上一个的最后一条数据的参数返回给服务器。
每次列表拉取都会限制条数，每个接口都会有默认值，请参考各个接口的使用说明，请不要将限制条数设置过大，将会因为数据过多导致接口返回慢。合理建议是app一次拉取50条左右。web一次拉取100条，或者使用默认值。



关于设备指令：
设备的型号需要提前通知我们配置，如果在导入设备号，指定型号的时候返回269877252，提示设备不支持，说明是该设备型号目前系统还未配置。无法实现相应的功能，
请联系客服配置相应版本。
每个设备对应的功能不一样，有些指令，可能由于版本限制，导致功能缺失。将会报对应的错误，有些设备功能也会与设备当前状态有关，



关于设备导入与添加：
1，首先需要明确设备型号是否已经配置，如果没有配置，请找我们的相关客服。
2，导入设备到系统中，需要相应权限，需要相应的权限，请找我们的相关客服。
3，调用device模块下的Load接口可以将设备导入到系统中，如果在调用该接口的时候，传入sgid，那么就可以同时完成添加的动作。
4，如果在Load的时候，没有传入sgid，那么也可以通过device模块下的Add接口添加设备到对应组织的分组中。
5，添加的权限目前经销商管理员都有，设备可以被自己的任意下级，或者下下级添加，如果设备被任意层级的下级添加之后
设备将将转到对应的下级中。当前账号可以拉取到对应的下级组织查看并操作到该设备。
6，当然不可以添加任何不属于自己任何一层上级的设备。
7，设备被终端组织添加之后，或者设备使用设备号登录绑定了手机号之后，该设备就被绑定，无法再次被其他终端组织添加，但是可以被自己的任意层级的下级添加转移。
被经销商转移组织分组，如果没有清除设备信息，并不会影响设备的终端组织关系





接口拉取顺序：
一般来讲，顺序如下：
1，user模块下Login接口登录，记下返回的sid和组织id；
2，user模块下SetAccount接口绑定手机号码以及初始密码
（如果已经绑定了手机号码以及修改过了初始密码，这个步骤可以跳过）
3，family模块下GetFamilyList获取到对应的分组id
（同样可以根据本接口拉取自己下级的组织以及对应的分组）
4，device模块Load导入到系统中，如果导入时没有填写sgid,需再调用Add接口添加到对应的组织的分组中。
5，可以通过family模块下通过GetRunInfo获取到设备目前的运行时数据

注意：不能每次调用操作接口的时候，都去调用Login接口换取sid。因为有效的sid的个数有限制。正常的操作是，Login登录之后，调用各种接口。如果不需要了，就调用注销接口，回收sid。

部分常见接口错误：
1，269877251  数据已变更,请刷新
表示该设备或者组织，或者分组，或者操作对应发生了转移，删除等操作。可能在其他终端完成，请刷新数据重新操作查看。

2，269877252 设备不支持
由于设备的版本号对应的功能不一致。导致一些设备并不具备某些权限，或者再特定的模式下，请先确认该设备的模式

3，269877282 当前状态不支持此操作
由于设备的版本号对应的功能不一致。在特定运动状态或者在线状态下不支持该功能，请先确认该设备的状态

4，268697607 参数无效
表示有些关键的参数是否没有填写，或者添加的参数是无效的？请参考对应的文档，检查参数是否填写以及正确

5，268697608 调用后台逻辑服务失败
可能服务器的程序出现异常，或者正在发布版本，请再重试

6，268697648 无法获取远端服务的描述信息
请检查传入的json串字段是否正确，或者传入进来的json串参数类型是否正确，是否将整形写为字符串了，或者字符串写为整形了等。
请参考接口对应文档中的示例，纠正字段已经字段类型。

7，268697629 操作频率过快,请稍后再试
可能被限频限速了，请参考上面的限频限速说明，或者登陆态过多使用，没有及时退出。请参考上面的sid说明

8，269877293 操作限制
请先确认该账号是否已经完成绑定手机号以及修改初始密码的操作，如果没有，请先调用user模块下的SetAccount接口，设置电话号码以及初始密码
请注意目前一个手机号码只能绑定一个组织账号，一个设备号。

9，269877324 该组设备数过多，请分批执行
有些接口批量操作对设备数量有做一定限制，请根据接口说明，在限制内做批量操作
